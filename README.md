🌍Wanderlust - Full Stack Marketplace
Wanderlust is a comprehensive full-stack web application designed for listing and discovering unique travel destinations. This project implements a full MVC (Model-View-Controller) architecture, secure user authentication, and cloud-based image management.

📁 Project Structure
/controllers: Route logic and business functions.

/models: Mongoose schemas for Listings, Reviews, and Users.

/public: Static assets including custom CSS and client-side JavaScript.

/routes: Express router modules for clean code separation.

/views: EJS templates, layouts, and partials (Navbar, Footer).

Tech Stack
Backend: Node.js, Express.js (v5)

Database: MongoDB Atlas

Authentication: Passport.js (Local Strategy)

Frontend: EJS, Bootstrap 5, CSS3

Image Hosting: Cloudinary

Deployment: Render
